# Mirante

Jogo mobile 3D (Android e iOS): suba a cidade inteira até o topo da Torre Farol.
Feito com Vite, Three.js e Capacitor. Toda arte e áudio são gerados por código.

- Especificação completa: [docs/GDD.md](docs/GDD.md)
- Guia de desenvolvimento, comandos e etapa atual: [CLAUDE.md](CLAUDE.md)

```bash
npm install
npm run dev        # jogo no navegador (http://localhost:5173)
npm run android    # build + roda no emulador/aparelho Android
```
